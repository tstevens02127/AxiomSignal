# AxiomSignal

Predictive operational intelligence platform for Latin American logistics and infrastructure operators.

## Features

- Live seismic monitoring
- Weather risk monitoring
- Operational risk scoring
- Geospatial risk visualization
- Geopolitical signal framework
- AI operational summaries

## Tech Stack

- Python
- Streamlit
- Folium
- Pandas
- Open-Meteo API
- USGS Earthquake API
